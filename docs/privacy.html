Privacy Policy

Last updated: 29 September 2026

"Untold Mysteries Publisher" is a private tool used only by the owner of the YouTube channel Untold Mysteries Daily to upload that channel's own videos.

What the app accesses

With the channel owner's permission, the app uses the YouTube Data API to upload videos, set their titles, descriptions and thumbnails, and read basic statistics for the owner's own channel. It does not access any other person's account or data.

What is stored

The app stores one access credential for the owner's channel as an encrypted secret in the owner's GitHub repository. It does not collect, sell or share personal data about viewers or anyone else.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

The channel owner can remove the app's access at any time at myaccount.google.com/permissions.
